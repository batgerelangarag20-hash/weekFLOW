How do I enable Google sync?
  1. Create a project in Google Cloud Console and enable Google Calendar API.
  2. Create an OAuth client ID for a Web application; add http://localhost:5173 to authorized JavaScript origins. Set up OAuth consent and add yourself as a test user if needed.
  3. Run WeekFLOW on http://localhost:5173 using the instructions in README.md.
  4. Paste the client ID above and click Connect & sync. WeekFLOW requests read-only calendar access.
